A small first step

Start with one example.

Install the gem, then follow the project guide for platform requirements and the full API.

Read the installation guide ↗

require "lookalike"
require "tessel"

actual = Tessel.read("actual.png")
result = Lookalike.compare(
  "expected.png", actual,
  mode: :channel, max_delta: 1
)
abort result.inspect unless result.match?
